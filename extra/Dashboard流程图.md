  API: /api/risk-metrics
  ┌─────────────────────────────────────────────────────────────────────┐
  │ get_risk_metrics()                                                 │
  │                                                                    │
  │ ① okx market orderbook BTC-USDT-SWAP --sz 20                      │
  │    → bids[0..19], asks[0..19]                                     │
  │    → btc_spread = (ask-bid)/bid*100                                │
  │    → btc_imbalance = sum(bid$)/sum(ask$)                           │
  │                                                                    │
  │ ② okx market candles BTC-USDT-SWAP --bar 1H --limit 4             │
  │    → chg_1h: cur_close vs prev_close                               │
  │    → chg_3h: cur_close vs 4th_close                                │
  │    → volume_trend: cur_vol / prev_vol (up/down/stable)             │
  │                                                                    │
  │ ③ okx market candles BTC-USDT-SWAP --bar 15m --limit 2            │
  │    → vol_15m_ratio (流动性趋势代理)                                 │
  │                                                                    │
  │ ④ 判定逻辑:                                                        │
  │    imbalance < 0.8 或 spread > 0.1% → 红色 "流动性警戒"             │
  │    imbalance < 0.9 或 spread > 0.05% → 黄色 "流动性偏弱"            │
  │    其他 → 绿色 "正常"                                              │
  │                                                                    │
  │ 输出: {last_updated, global_status, metrics(5项)}                   │
  └─────────────────────────────────────────────────────────────────────┘

  API: /api/macro-events
  ┌─────────────────────────────────────────────────────────────────────┐
  │ get_macro_events()                                                 │
  │                                                                    │
  │ ① okx --profile live news economic-calendar                        │
  │    --region united_states --importance 3 --before now --after +7d   │
  │    → 高影响宏观事件列表                                             │
  │                                                                    │
  │ ② 时间格式统一: OKX "2026/5/21" → Python strftime "%Y/%m/%d"       │
  │    (已修复时间格式不匹配 bug)                                       │
  │                                                                    │
  │ ③ 筛选: 按时间排序 → 最近未来事件 → 计算倒计时                      │
  │                                                                    │
  │ ④ 风险评级: RATE_DECISION/FOMC ≥2 → high, ≥1 → medium              │
  │                                                                    │
  │ 输出: {current_risk, next_event, countdown_str, recent_events}     │
  └─────────────────────────────────────────────────────────────────────┘

  API: /api/ai-regime
  ┌─────────────────────────────────────────────────────────────────────┐
  │ get_alpha_breadth()                                                │
  │                                                                    │
  │ ① okx market tickers SWAP --json                                   │
  │    → 341 个合约, 每个含 last + open24h                             │
  │    → 过滤 instId 含 -USDT-SWAP                                     │
  │    → chg24h% = (last-open24h)/open24h*100                          │
  │                                                                    │
  │ ② 统计: 上涨占比 up_pct, 中位 median, 均值 avg                     │
  │    暴涨>10%: extreme_up[], 暴跌>10%: extreme_down[]                │
  │                                                                    │
  │ ③ okx market ticker BTC-USDT-SWAP → BTC 24h chg%                  │
  │                                                                    │
  │ ④ Altseason 判定:                                                  │
  │    up_pct >= 70 → ALT_SEASON                                       │
  │    up_pct >= 50 → ALT_PULLBACK                                     │
  │    否则 → CHOP                                                     │
  │                                                                    │
  │ 输出: {total, up_pct, median, avg, btc_24h, altseason, ...}       │
  └──────────────────────────────┬──────────────────────────────────────┘
                                 │
                                 ▼
  ┌─────────────────────────────────────────────────────────────────────┐
  │ get_ai_regime(alpha_data)                                          │
  │                                                                    │
  │ ① 构建 prompt: system(角色+格式) + user(Alpha数据)                  │
  │                                                                    │
  │ ② call_deepseek(system, user, max_tokens=1024)  ← kol_agent 复用   │
  │    → LLM 返回 JSON {regime, conf, judgment, support, counter}      │
  │                                                                    │
  │ ③ 容错: LLM 失败 → 用 alpha_data 基础统计做 fallback               │
  │                                                                    │
  │ ④ 24h timeline: 存储到 extra/regime_timeline.json                   │
  │    → 追加当前小时 regime → 保留最近 24 条                           │
  │                                                                    │
  │ 输出: {current_regime, confidence, judgment_text,                   │
  │        evidence_support, evidence_counter, timeline_24h}            │
  └─────────────────────────────────────────────────────────────────────┘
