## 二、run_round() 完整流程

```
run_round() 入口
│
├─ _load_setting() × 3          ← 从 DB trading_settings 读阈值
│  fund_source_min (default 30)    表面同源% > 此值 = 有隐藏关联
│  surface_top10_max (default 40)  表面 top10% < 此值 = 不集中
│  max_days (default 7)            观察池最长停留
│
├─ _write_status("scanning")
│
├─ Step A ─────────────────────────────────────────────────
│  │
│  │  onchainos token hot-tokens
│  │  --chain bsc --rank-by 10 --time-frame 4
│  │  --top10-hold-percent-max <surface_top10_max>
│  │  --holders-min 5000 --market-cap-min 500000
│  │  --limit 30
│  │
│  ▼
│  candidates: [{token, token_address, chain, top10_hold_pct, holders, mc}, ...]
│  │  top10_hold_pct 已是百分比 (e.g. 34.73 = 34.73%)
│  │
│  └─ 空? → return (本轮无候选)
│
├─ _write_status("analyzing")
│
├─ Step B ─────────────────────────────────────────────────
│  │
│  │  for each candidate:
│  │  │
│  │  ├─ fetch_cluster_overview(addr)
│  │  │  │  onchainos token cluster-overview --address <addr> --chain bsc
│  │  │  │
│  │  │  ▼ _pct() 转换: 小数(0-1) → 百分比(0-100)
│  │  │    cluster_concentration: "Low"|"Medium"|"High"
│  │  │    top100_holdings_pct:    98.01  (%)
│  │  │    holder_same_fund_pct:   41.33  (%)  ← 关键背离指标
│  │  │    holder_new_addr_pct:    0.33   (%)
│  │  │    holder_same_creation:   0.67   (%)
│  │  │    rug_pull_pct:           1.0    (%)
│  │  │
│  │  │  sleep(0.3)
│  │  │
│  │  ├─ fetch_cluster_list(addr)
│  │  │  │  onchainos token cluster-list --address <addr> --chain bsc
│  │  │  │
│  │  │  ▼ _safe_float() 保留小数
│  │  │    [{holding_percent: 0.4376, trend_type: ["buy"],
│  │  │      addresses: [{is_exchange: true/false,
│  │  │                   is_contract: true/false,
│  │  │                   is_kol: true/false,
│  │  │                   holding_percent: 0.4376}]}]
│  │  │
│  │  │  sleep(0.3)
│  │  │
│  │  ├─ 计算有效集中度:
│  │  │  effective_conc = 0.0
│  │  │  for each cluster:
│  │  │    if NOT has_exchange AND NOT has_contract:
│  │  │      effective_conc += cluster.holding_percent  (小数累加)
│  │  │  effective_conc × 100 → 百分比 (e.g. 5.0%)
│  │  │
│  │  ├─ 背离检测:
│  │  │  fund_pct > fund_source_min   (e.g. 41.33 > 30)
│  │  │  AND top10_pct < surface_top10_max  (e.g. 34.73 < 40)
│  │  │  → divergence_detected = True
│  │  │  → divergence_score = (41.33-30)*(40-34.73)/100 = 0.60
│  │  │
│  │  └─ snapshot 写入 snapshots[] + divergence_tokens[]
│  │
│  ▼
│  with conn:                          ← 第一个 DB 连接
│    onchain_snapshot_insert_batch()    → onchain_snapshots 表
│    onchain_snapshots_purge_old(50)    → 清理 50 轮前的旧快照
│
├─ Step C ─────────────────────────────────────────────────
│  │
│  │  with conn:                       ← 第二个 DB 连接
│  │    existing_pool = onchain_pool_get_all()  → {token: row}
│  │    _load_setting("onchain_scan_interval_hours") → scan_interval
│  │
│  │    for each divergence_token:
│  │    │
│  │    │  rounds_in_pool = existing.rounds_in_pool + 1 (or 1 if new)
│  │    │  days_in_pool = rounds_in_pool × scan_interval / 24
│  │    │  existing_stage = existing.pool_stage or "observation"
│  │    │                    ↑ 保留已有 stage, 不降级
│  │    │
│  │    │  onchain_pool_upsert({
│  │    │    token, token_address, chain,
│  │    │    pool_stage: existing_stage,  (observation or actionable)
│  │    │    surface_top10_pct, effective_concentration,
│  │    │    fund_source_same_pct, divergence_detected: 1,
│  │    │    days_in_pool, rounds_in_pool,
│  │    │    first_seen_at, last_updated_at
│  │    │  })  → onchain_pool 表 (INSERT OR REPLACE)
│  │
│  ├─ Step D ─────────────────────────────────────────────
│  │  │
│  │  │  cutoff = now - max_days (ISO 字符串)
│  │  │
│  │  │  for each existing_pool entry (旧的快照):
│  │  │    if pool_stage == "observation"
│  │  │    AND first_seen_at < cutoff:
│  │  │      onchain_pool_remove(token)
│  │
│  ├─ Step E ─────────────────────────────────────────────
│  │  │
│  │  │  if round_number % 2 == 0:     ← 每 2 轮执行
│  │  │  │
│  │  │  │  obs_tokens = onchain_pool_get_all("observation")
│  │  │  │
│  │  │  │  for each observation token:
│  │  │  │  │
│  │  │  │  ├─ _check_lp_reserve(conn, token, addr, round)
│  │  │  │  │  │
│  │  │  │  │  │  fetch_liquidity(addr, "bsc", token_symbol=token)
│  │  │  │  │  │  → 只累加匹配 token_symbol 的数量
│  │  │  │  │  │  → 写入 onchain_lp_snapshots
│  │  │  │  │  │  → 读取最近 4 轮 LP 快照
│  │  │  │  │  │  → 需要 ≥3 轮 → 计算变化率
│  │  │  │  │  │  → (older-newer)/older × 100  ← LP减少时为正
│  │  │  │  │  │  → 返回 (trend_label, score)
│  │  │  │  │  │     加速减少=80, 弱加速=50, 轻微=25, 开始=20, 稳定=10
│  │  │  │  │  │
│  │  │  │  │  │  sleep(0.3)
│  │  │  │  │  │
│  │  │  │  │  ├─ _check_gas_seeding(addr, pool_entry)
│  │  │  │  │  │  │
│  │  │  │  │  │  │  fetch_cluster_overview(addr) → 当前值
│  │  │  │  │  │  │  │
│  │  │  │  │  │  │  │  打分 (每满足一项 +1, ≥3=强, ≥2=弱):
│  │  │  │  │  │  │  │  ① new_addr_pct > 2%          (新地址多)
│  │  │  │  │  │  │  │  ② fund_same_pct > 35%        (同源占比高)
│  │  │  │  │  │  │  │  ③ same_creation_pct > 5%     (同时创建)
│  │  │  │  │  │  │  │  ④ new_addr_pct > prev_new+1  (在上升)
│  │  │  │  │  │  │  │
│  │  │  │  │  │  │  │  prev_new = pool_entry.prev_new_addr_pct
│  │  │  │  │  │  │  │  只在上次 signal≥1 时更新
│  │  │  │  │  │  │  │
│  │  │  │  │  │  │  └─ 返回 (signal, new_addr_pct)
│  │  │  │  │  │  │
│  │  │  │  │  │  sleep(0.3)
│  │  │  │  │  │
│  │  │  │  │  ├─ _check_cex_staging(addr, pool_entry)
│  │  │  │  │  │  │
│  │  │  │  │  │  │  fetch_cluster_list(addr) → 找有 is_exchange 的集群
│  │  │  │  │  │  │  │
│  │  │  │  │  │  │  │  ≥3 集群 且 >5%  → 2 (强)
│  │  │  │  │  │  │  │  ≥1 集群 且 >2%  → 1 (弱)
│  │  │  │  │  │  │  │  否则 → 0
│  │  │  │  │  │  │  │
│  │  │  │  │  │  │  └─ 返回 signal
│  │  │  │  │  │
│  │  │  │  │  └─ _compute_confidence(lp, gas, cex)
│  │  │  │  │     │
│  │  │  │  │     │  LP × 0.50  (80×0.50 = 40)
│  │  │  │  │     │  Gas×50×0.35 (2×17.5 = 35)
│  │  │  │  │     │  CEX×50×0.15 (2×7.5 = 15)
│  │  │  │  │     │  = 90 (最高)
│  │  │  │  │     │
│  │  │  │  │     └─ confidence ≥ 50?
│  │  │  │  │        YES → 晋级 actionable
│  │  │  │  │        NO  → 更新信号, 不晋级
│  │  │
│  │  ├─ _write_status("idle") + 最终计数
│  │
│  └─ print 本轮统计
│
└─ 返回 scanner_loop → sleep(interval_hours × 3600)
```

## 五、Web 页面渲染

```
GET /onchain
│
├─ Panel 1: 扫描状态 (每60s刷新)
│  │  GET /api/onchain/status
│  │  → onchain_scanner_status 表
│  │  → {stage, round_number, tokens_scanned, pool_size, actionable_size, detail}
│  │
│  │  显示: ●运行中 | #12 | 已扫描28 | 观察池5 | 可建仓2 | 下次扫描2h后
│
├─ Panel 2: 观察池 (每60s刷新)
│  │  GET /api/onchain/pool?stage=observation
│  │  → onchain_pool 表 (pool_stage='observation')
│  │  → 每条附加 sparkline (从 onchain_snapshots 最近6轮 effective_concentration)
│  │  → days_in_pool 从 first_seen_at 实时计算
│  │
│  │  表格列: 代币 | 链 | 表层Top10% | 有效集中度% | 资金同源% | 趋同 | 入池天数 | 集中度趋势
│  │  趋势列: Unicode sparkline (▁▂▃▄▅▆▇█) + ↑↓→ + 最新值%
│
└─ Panel 3: 可建仓 (每60s刷新)
   │  GET /api/onchain/pool?stage=actionable
   │  → onchain_pool 表 (pool_stage='actionable')
   │
   │  表格列: 代币 | 链 | LP储备趋势 | Gas播种 | CEX上架 | 置信度% | 入池天数
```
