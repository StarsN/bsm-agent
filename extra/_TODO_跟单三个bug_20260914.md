# 跟单（alphafox）三个 bug —— 2026-09-14 用户报

> 状态：**1、3 已修并验证**；**2 已定位根因、等用户定方案**。

## BUG 1（已修）「我手动平仓，跟单还按交易员开单」

**用户确认的语义**：手动平仓（在系统里或在交易所）= **这一笔不再跟单**，
直到交易员开新的一笔。

**根因**：`alphafox_live._align_qty` 的"交易所持仓消失（手动平仓/强平）"分支以前只把
**实盘记录**收敛 CLOSED，**纸盘那一笔继续挂托管** → 交易员再加仓时纸盘跟着变大，
而实盘被 `_mirror_missing` 的"已平记录不自动重开"闸门挡住 → 纸盘/实盘永久分叉；
交易员新开一笔时又照常跟（用户看到的"还在按交易员开单"）。

**改法**：抽出 `_close_paper_leg(token, side, advice)`（`_settle_unmanaged` 与
`_align_qty` 共用），实盘持仓消失时**连纸盘这一笔一起收尾**（留痕
"实盘持仓消失（手动平仓/强平），不再跟这一笔"）。
之后交易员再加/减/平仓：`_our_position` 找不到活跃仓 → 不动作；交易员**新开** → 新纸盘行 → 照常跟。

**验证**：`extra/test_alphafox_live.py` 测试 27 扩了 4 条断言（纸盘收尾 + 再加仓不复活/不新建记录）；
变异 **M162** 锚定；M4/M74 的锚点随重构更新后复测通过。

## BUG 2（已修·选项1）「交易员加仓 4 次，系统只加了 2 次」

**用户实例**：ETH 09-14 —— 交易员开 1 笔 + 加 4 笔；系统开 1 + 加 2。

**根因**：信号按**持仓净变化**识别（`process` 对比本轮 vs 上轮 `positions`），
探测间隔 `alphafox_poll_seconds`（默认 15s）→ 间隔内的多次加仓被并成一次净变化。
服务器实测：`OPEN 143.912 → ADD 238.169 → ADD 357.027`（净变化 2 次 = "加了 2 笔"）。

**修法（选项 1，用户选定）**：用平台快照里的 `latestOrders`
（每笔带 `canonicalAction` = OPEN/ADD/REDUCE/CLOSE + `time` + `executedQty`）
数出"这次净变化背后真有几笔加仓"，补记成 N 条 ADD 信号 → 实盘按份数各加一份、
日志/页面次数与交易员一致。

- 新增 `_new_action_orders(trader_id, symbol, action, data, cap=20)`：按
  `(symbol, action, time, executedQty)` 内容键去重（每交易员最近 300 个键），
  返回本次**新增**的笔数；字段缺失/脏值 → 返回 0（调用方按 1 笔处理 = 旧行为）。
- 只有 `action == "ADD"` 且 `executed` 时补记（REDUCE 仍按净变化，避免与
  "减到零转 CLOSE"的逻辑打架）；纸盘**仍按净额对齐一次**（总量本来就对）。
- `set_follow(False)` 清 `_seen_orders`（与 `_prev_snap` 同处）。

**验证**：`extra/test_alphafox_trade.py` 新增第 55 段 5 条断言
（3 笔还原、纸盘只对齐一次、同批流水去重、只补新增、日志笔数一致）；
变异 **M163/M164** 锚定。

## BUG 3（已修）托管页显示 纸盘/实盘

- `/api/alphafox/board`：持仓行补 `ex_entry`（交易所开仓价）、历史行补 `live_entry`
  （实盘记录开仓价）；`ex_pnl`/`live_pnl` 本来就有。
- 页面 ③跟单持仓、④历史持仓：**开仓价**、**浮动盈亏/盈亏** 都渲染成
  `纸盘 / 实盘`（表头加"纸盘/实盘"小字）。
- 验证：`extra/_check_af_board.py` 新增 4 条断言（含前端源码断言）。
