# 调研：Bnsbot（bnsbot.qianyuwing.com）— 币安广场自动发帖 SaaS（2026-10-07）

只读调研（主页 + 前端 JS 包 + 公开接口），未做任何鉴权绕过/爆破/admin 探测。

## 一、产品定位与商业模式

**一句话**：帮用户把自己的**币安广场账号**做成"24 小时自动发帖机"——自动抓素材 → AI 写成带 `$币种` 的帖子 →
按设定节奏用**币安广场官方 OpenAPI** 发到用户账号 → 读者点币种去交易 → 用户拿 **cashtag 返佣**（内容挖矿）。

- 注册免费（Turnstile 人机验证），Key 加密存储、敏感词过滤；
- **免费档**：1 账号、24 帖/天、最短间隔 20 分钟、6 类素材源、无自定义模板/图片/X 同步；
- **高级档**（申请制 `/api/advanced/apply`）：3 账号、100 帖/天、最短间隔 5 分钟、10 类素材源、
  自定义模板 + 配图（图片全量 vs 免费档 34%）+ **X（推特）同步**；
- 平台自带推广：页面 promo 带他们自己的币安返佣链接（`bsmkweb.cc/join?ref=QY001`）。

## 二、素材引擎（40 个源）——与我们系统高度同源

**新闻类**：金十数据、律动BlockBeats、华尔街见闻、财联社、PANews、Odaily星球日报、链捕手、
深潮TechFlow、吴说区块链、火星财经、Foresight News、Techub News、币安新闻、全天候金融洞察、
韩国交易所上新、代币解锁 / **币安公告、TG 频道（自选）、X 推文**。
**行情/衍生品类**：币安行情异动、资金费率、持仓异动、爆仓监控、多空比、关键价位、RSI 超买超卖、
均线突破、新币开盘 / 恐惧贪婪指数 / ETF 资金流 / 稳定币增发销毁 / Hyperliquid 鲸鱼 / DEX 热门榜。
**热度榜类**：币安广场热点、币安 Alpha / 微博热搜、抖音热榜、头条热榜、B站热搜、百度热搜。

技术要点（从其设置文档字符串提取）：
- **TG 素材 = `t.me/s/<频道>` 公开预览页抓取**（示例频道 theblockbeats / foresightnews），
  只支持公开频道、"每轮每频道抓 X 条" —— **与我们 event_agent 的金十抓取是同一技术路线**；
- **Hyperliquid 鲸鱼 = 公开成交流 WebSocket**：按单笔订单金额阈值判定（≥$1B 计 85 分、≥$300M 计 75 分），
  taker 成交记录确认开多/开空/平多/平空；
- 素材库当前**活跃素材 138 条**（`materialsActive`），模板 **1003** 个，**AI 人设 7 种**。

## 三、产品链路（前端路由 + 接口推断）

```
素材（40 源）→ 模板(1003)/AI 人设(7) 生成帖子 → 敏感词过滤 → 审核队列（approve/discard）
→ 按节奏（间隔 20/5 分钟、每日 24/100 帖）→ 币安广场 OpenAPI 发帖 → X 同步（高级档）
+ 多账号管理（绑定 Key、post-now 立即发、preview 预览、resume 续发）
+ 通知/统计（insights）/通知中心
```

## 四、接口暴露情况（用户核心问题）

**前端可见完整 API 面（约 75 个路径，Vite SPA，全部 /api/*）**：

| 分类 | 路径 | 鉴权（实测） |
|---|---|---|
| 公开 | `/api/auth/config`（登录页配置+推广链接）、`/api/public/overview`（产品分层介绍）、`/api/auth/{register,login,login/2fa,captcha,captcha-error}` | **200 可访问**（本就该公开） |
| 用户 | `/api/me*`（2FA/密码/telegram 绑定/删号）、`/api/accounts*`（账号 Key/post-now/preview/resume/xsync）、`/api/posts*`（review/approve/discard）、`/api/materials`、`/api/templates*`、`/api/notifications*`、`/api/stats/*` | **实测 401**（`/api/meta`、`/api/stats/overview`、`/api/me` 均"请先登录"）✓ |
| 管理 | `/api/admin/*` 全套：users（含 reset-2fa/reset-password）、settings、sources、telegram、sensitive、templates、xsync、audit、overview、insights、breaker/reset、maintenance/backup、apple-ids、alerts/test | **未探测**（合法边界内不碰 admin） |

**结论**：没有发现"无鉴权的数据接口"——用户/数据类全部要求登录；错误 envelope 统一（`{ok,error:{code,message}}`），
`robots.txt` 也明确 Disallow 控制台与 `/api/`。唯一"暴露面"是那套 `/api/admin/*` 的管理接口存在性
（应有强鉴权，从公开信息无法判断其实现质量）。

## 五、对我们的参考点

1. **同一路线的产品化对照**：TG 公开频道抓取、币安衍生品异动、Hyperliquid 鲸鱼 WS——我们系统里大多已有同源数据，
   他们做成了"自动发帖+返佣"的商业闭环，我们做的是"Agent 交易 + 事件雷达"，可借鉴其**素材分层与节奏参数**
   （20/5 分钟间隔、24/100 帖/天上限、图片比例分层）；
2. **"AI 人设/模板"概念**：1003 模板 + 7 人设（发帖口吻），类似我们把图解卡片做成标准化结构；
3. 若研究其数据源配置细节：其设置文档字符串在前端 JS 里（`api-*.js`），含每个源的阈值参数说明。
